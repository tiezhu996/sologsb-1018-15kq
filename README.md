# 声律场 · 口语发音与韵律练习工作台

使用 Svelte 与 Skeleton 从零实现的口语练习工作台。学习者可以录入句子、划分意群并标注重音、停顿和语调，随后录音、选择回听范围、逐段比较偏差；教师反馈与错词分类会和具体尝试、意群绑定。

## 功能

- 句子录入、标点智能切分、意群增删与排序。
- 逐意群标注重音词、重音强度、停顿毫秒数和语调走向。
- **带历史的版本工作流**：编辑句子或意群前自动冻结当前稿为只读历史版本，再克隆出新草稿承接改动；版本号递增。
- 旧尝试永远归属当时冻结的版本，按当时的意群文本、意群顺序与回听范围回看，后续改动不会串段。
- 恢复历史版本会以其句子与意群生成一份全新草稿，原版本保留、可追溯；旧尝试不并入新稿。
- 调用浏览器麦克风录音，支持同一版本内多轮尝试；未授权麦克风时保留可校对的离线模拟轮次。
- 每一轮尝试独立保存回听起点、终点、准确度、节奏、偏差、自评和错词分类。
- 教师可按意群在任意一轮尝试上留下多轮反馈。
- 练习进度、目标轮次、准确度、偏差和错词分类统计；进度页按版本列出尝试数与错词总数。
- 使用 IndexedDB 持久化录音和全部标注，网络中断时继续编辑，不会因刷新丢失。
- **已有本机数据首次打开无损迁移**：旧单份稿整体成为 v1，旧尝试、反馈和错词关系仍按原有意群显示；首次保存后升级为 v2。
- 撤销/重做覆盖冻结、恢复等全部操作；Service Worker 缓存应用壳，已打开的生产页面可离线访问。
- 响应式手机/桌面布局和键盘工作流。

## 技术栈

- Svelte 4
- Vite 5
- TypeScript
- Skeleton 2
- Tailwind CSS 3

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器使用本地端口 `5175`，该端口不构成宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1018 .
docker run --rm -p 10018:80 sologsb-1018
```

最终镜像使用 nginx 在容器 `80` 端口提供构建产物。宿主端口由根编排文件维护，源码和 Dockerfile 没有硬编码宿主端口。

## 本地数据与麦克风

- 录音 Blob、版本、标注、尝试、反馈和进度保存在 IndexedDB。
- 升级前的单份稿（持久化 v1）首次打开时自动无损迁移为版本模式（v2）：原句与意群冻结为 v1，旧尝试、评分、错词、反馈关系原样保留。
- IndexedDB 不可用时会退化为 `localStorage`，但浏览器安全限制下不保存原始录音 Blob。
- 麦克风从未上传到服务器；清除站点数据会永久删除本机练习。
- 生产页面首次加载后由 Service Worker 缓存，离线状态仍可继续标注和录音。
