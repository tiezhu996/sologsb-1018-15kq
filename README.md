# 声律场 · 口语发音与韵律练习工作台

使用 Svelte 与 Skeleton 从零实现的口语练习工作台。学习者可以录入句子、划分意群并标注重音、停顿和语调，随后录音、选择回听范围、逐段比较偏差；教师反馈与错词分类会和具体尝试、意群绑定。练习按版本演进：改动句子或意群前自动保存快照，历史版本只读、可追溯，并可恢复为新草稿。

## 功能

- 句子录入、标点智能切分、意群增删与排序。
- 逐意群标注重音词、重音强度、停顿毫秒数和语调走向。
- 调用浏览器麦克风录音，支持多轮尝试；未授权麦克风时保留可校对的离线模拟轮次。
- 每一轮尝试独立保存回听起点、终点、准确度、节奏、偏差、自评和错词分类。
- 教师可按意群留下多轮反馈。
- **版本化工作流**：
  - 当前草稿已有尝试时，再编辑句子或意群文本 / 增删 / 排序 / 智能切分会先把草稿封存为历史版本（含当时的句子、意群顺序与全部尝试），再派生新草稿。
  - 旧尝试始终挂在封存版本上，按当时的意群文本、顺序和回听范围回看，后续改动不会串段。
  - 历史版本只读；「以此版本生成新草稿」会复制其句子与意群产生新草稿，原版本保留、可追溯。
  - 韵律标注（重音、停顿、语调、提示）微调不产生新版本。
  - 撤销 / 重做覆盖封存与恢复操作，离线保存照常可用。
- 练习进度按版本统计：进度页列出每个历史版本的尝试数、错词总数与保存时间，并汇总全版本数据。
- 使用 IndexedDB 持久化录音和全部标注，网络中断时继续编辑，不会因刷新丢失。
- **旧版单份数据无损迁移**：首次打开自动升级为版本结构，旧尝试、反馈、错词关系和回听范围按原有意群原样显示（IndexedDB 与 localStorage 兜底两种存储形态均支持）。
- Service Worker 缓存应用壳，已打开的生产页面可离线访问。
- 响应式手机/桌面布局和键盘工作流。

## 技术栈

- Svelte 4
- Vite 5
- TypeScript
- Skeleton 2
- Tailwind CSS 3

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器使用本地端口 `5175`，该端口不构成宿主映射。容器生产环境仅监听 `80`。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

构建结果位于 `dist/`。

## Docker

```bash
docker build -t sologsb-1018 .
docker run --rm -p 10018:80 sologsb-1018
```

最终镜像使用 nginx 在容器 `80` 端口提供构建产物。宿主端口由根编排文件维护，源码和 Dockerfile 没有硬编码宿主端口。

## 本地数据与麦克风

- 录音 Blob、标注、尝试、反馈、历史版本和进度保存在 IndexedDB。
- IndexedDB 不可用时会退化为 `localStorage`，但浏览器安全限制下不保存原始录音 Blob。
- 旧版（无版本）本机数据在首次打开时无损迁移：原意群与全部尝试组成冻结的初始版本，可继续回看；有旧尝试时会自动派生一份沿用原意群的编辑草稿。
- 麦克风从未上传到服务器；清除站点数据会永久删除本机练习。
- 生产页面首次加载后由 Service Worker 缓存，离线状态仍可继续标注和录音。
